# Notification Hub

**Notification Hub** — это простой клиент-серверный мессенджер на Python с консольным центром управления процессами.

Проект демонстрирует базовую архитектуру обмена сообщениями через сокеты: сервер принимает сообщения от клиентов и периодически рассылает их всем подключённым участникам. Управление запуском сервера и клиентов вынесено в отдельный интерактивный менеджер.

## Возможности

- **Сервер на сокетах** — принимает подключения и сообщения от клиентов.
- **Периодическая рассылка** — каждые 5 секунд сервер отправляет накопленные сообщения всем клиентам.
- **Многопоточность** — каждый клиент обслуживается в отдельном потоке.
- **Центр управления** — консольный менеджер для запуска сервера и клиентов и просмотра их статуса.
- **Подтверждение приёма** — отправитель получает ответ после успешной обработки сообщения.

notification-hub/

├── server.py # Сервер: приём и рассылка сообщений
├── client.py # Клиент: подключение и отправка сообщений
└── README.md

## Требования

- **Python 3.8+**
- Стандартная библиотека (`socket`, `threading`, `subprocess`) — внешние зависимости не нужны.
- ОС: Windows (менеджер использует `CREATE_NEW_CONSOLE`), сервер и клиент кроссплатформенны.

## Установка

## Использование
Для запуска был реализован менеджер запуска, с помощью которого можно пользоваться функционалом приложения
```bash
python manager.py
```
В данном менеджере предоставляется командная строка с следующими командами:
##### Запуск серверного приложения
```bash
server
```
##### Запуск клиентского приложения
```bash
client
```
##### Вывод запущенных терминалов
```bash
list
```
##### Остановка всех терминалов
```bash
stop
```
##### Выход из приложения-менеджера
```bash
exit
```
